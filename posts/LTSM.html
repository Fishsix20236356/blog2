📋 指标详细说明

MSE (均方误差)

衡量预测值与真实值之差的平方的平均值，是回归问题中最常用的损失函数之一。

重要性: 85%
R² (决定系数)

表示模型对因变量变化的解释程度，值越接近1表示模型拟合效果越好。

重要性: 90%
Delta MSE

衡量预测值变化量与真实值变化量之差的平方的平均值，评估模型对趋势的预测能力。

重要性: 75%
MAE (平均绝对误差)

衡量预测值与真实值之差的绝对值的平均值，对异常值不那么敏感。

重要性: 80%
Huber Loss

结合了MSE和MAE的优点，在误差较小时为平方损失，较大时为线性损失。

重要性: 70%
Log-Cosh Loss

一种比MSE更平滑的损失函数，对异常值具有良好的鲁棒性。

重要性: 65%
Quantile Loss

用于分位数回归，衡量特定分位数下的预测误差，适用于不确定性量化。

重要性: 60%
Soft-DTW Loss

基于动态时间规整的损失函数，用于衡量两个时间序列的相似性。

重要性: 55%
Dilated Loss

考虑了时间序列中长期依赖关系的损失函数，适用于捕捉不同时间尺度的模式。

重要性: 50%
Phase Loss

衡量两个时间序列在相位上的差异，评估频率成分的时间偏移。

重要性: 45%

🔢 数学公式详解

MSE (均方误差)
$$\text{MSE} = \frac{1}{n} \sum_{i=1}^{n} (Y_i - \hat{Y}_i)^2$$

其中 $Y_i$ 是真实值，$\hat{Y}_i$ 是预测值，$n$ 是样本数量

R² (决定系数)
$$R^2 = 1 - \frac{\sum_{i=1}^{n} (Y_i - \hat{Y}_i)^2}{\sum_{i=1}^{n} (Y_i - \bar{Y})^2}$$

其中 $\bar{Y}$ 是真实值的均值

Delta MSE
$$\text{Delta\_MSE} = \frac{1}{n-1} \sum_{i=2}^{n} ((Y_i - Y_{i-1}) - (\hat{Y}_i - \hat{Y}_{i-1}))^2$$

衡量连续时间点之间变化量的预测精度

MAE (平均绝对误差)
$$\text{MAE} = \frac{1}{n} \sum_{i=1}^{n} |Y_i - \hat{Y}_i|$$

使用绝对值而非平方，对异常值更加鲁棒

Huber Loss
$$L_{\delta}(y, \hat{y}) = \begin{cases} \frac{1}{2}(y - \hat{y})^2 & \text{for } |y - \hat{y}| \le \delta \\ \delta |y - \hat{y}| - \frac{1}{2}\delta^2 & \text{otherwise} \end{cases}$$

$\delta$ 是控制从平方损失转换为线性损失的阈值

Log-Cosh Loss
$$L(y, \hat{y}) = \sum_{i=1}^{n} \log(\cosh(\hat{y}_i - y_i))$$

$\cosh$ 是双曲余弦函数，提供平滑的梯度

Quantile Loss
$$L_q(y, \hat{y}) = \sum_{i: y_i \ge \hat{y}_i} q(y_i - \hat{y}_i) + \sum_{i: y_i < \hat{y}_i} (1-q)(\hat{y}_i - y_i)$$

$q$ 是分位数参数，通常取0.5表示中位数

Soft-DTW Loss
基于动态时间规整算法的软化版本
公式较为复杂，涉及动态规划和软最小值运算
Dilated Loss
基于扩张卷积的损失函数
捕捉不同时间尺度的特征模式
Phase Loss
基于傅里叶变换的相位差异
评估频域中的时间对齐程度
