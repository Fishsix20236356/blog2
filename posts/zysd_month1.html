关键处理技术说明

滑动窗口机制

窗口大小=1实现密集预测，每个窗口预测未来4个时间点。使用重叠平均法恢复连续序列，有效解决密集预测中的序列恢复问题。

数据对齐技术

时间戳精确匹配（从第48行开始），预测值恢复后长度与原始数据长度保持一致（原始数据长度 - context_len）。

评估指标计算

使用自定义metric函数计算多种指标：MAE（平均绝对误差）、MSE（均方误差）、RMSE（均方根误差）、MAPE（平均绝对百分比误差）等。

滑动窗口处理代码

def csv_to_api_format(csv_file, context_len=48, prediction_len=4, window_size=1):
    # 列名到Unicode映射
    column_mapping = {
        '小时平均SI': '\u5c0f\u65f6\u5e73\u5747SI',
        # ...其他11个变量映射...
    }

    df = pd.read_csv(csv_file)
    data_samples = []

    # 滑动窗口切分
    total_points = len(df)
    num_segments = (total_points - context_len) // window_size + 1

    for i in range(num_segments):
        start_idx = i * window_size
        end_idx = start_idx + context_len
        context_data = {}

        for col in numeric_columns:
            unicode_col = column_mapping[col]
            values = df[col].iloc[start_idx:end_idx].tolist()
            context_data[unicode_col] = values

        data_samples.append({"context": context_data})

    return {
        "data": data_samples,
        "context_len": context_len,
        "prediction_len": prediction_len,
        "window_size": window_size
    }

# 重叠平均法恢复序列
result_data = np.array([item["prediction"]["小时平均SI"] for item in data["data"]])
result_data = np.expand_dims(result_data, axis=-1)

recovered_sum = np.zeros((result_data.shape[0]+result_data.shape[1]-1, 1))
recovered_count = np.zeros((result_data.shape[0]+result_data.shape[1]-1, 1))

for i in range(result_data.shape[0]):
    start = i
    end = i + result_data.shape[1] - 1
    window = result_data[i]
    recovered_sum[start:end+1] += window
    recovered_count[start:end+1] += 1

recovered_data = np.divide(recovered_sum, recovered_count, where=(recovered_count > 0))

# 计算评估指标
def metric(preds, trues):
    mae = np.mean(np.abs(preds - trues))
    mse = np.mean((preds - trues)**2)
    rmse = np.sqrt(mse)
    mape = np.mean(np.abs((trues - preds) / trues))
    return mae, mse, rmse, mape, mspe
